# Screenshots

Captured from a real run of the app at 1600 x 900, device pixel ratio 2, then
resized to 1920 wide and encoded as JPEG so the repository stays small.

Nothing here is a mock-up or a composite. Every frame is the running build.

| File | What it shows |
|---|---|
| `01-title.jpg` | Title screen with live ephemeris, the four provenance labels, and the real NASA frames the procedures reveal |
| `02-survival-guide.jpg` | The complete Mars survival guide, ordered by how fast each thing kills you |
| `03-briefing.jpg` | Mission briefing: the site, the science question, the crew member, the three stations |
| `04-planner.jpg` | Traverse planner: three routes, forecast margins, synthetic height field with map layers |
| `05-real-site-nasa-data.jpg` | HiRISE 25 cm imagery, slope from the 1 m DTM, Perseverance's localized traverse, route measured on real terrain |
| `06-surface-traverse.jpg` | Walking the route. The instruments are windows now, so the screen is the planet |
| `07-objectives.jpg` | Mission objectives in three tiers, each with why it matters out there |
| `08-procedure-running.jpg` | A field procedure playing, with its cuff checklist and the mission clock compressed |
| `09-procedure-result-nasa-image.jpg` | The result card: what you found, the real NASA image of the same operation, and the survival note |
| `10-downlink-to-earth.jpg` | The two-hop downlink, with the direct-to-Earth comparison that explains relay orbiters |
| `11-nasa-feed.jpg` | The public feed, with a packet in flight and a live light-time countdown |
| `12-dust-storm.jpg` | A regional dust storm at onset: opacity 1.97, visibility 8 km, 10% of the sunlight left, abort recommended |
| `13-debrief.jpg` | The debrief — this run ran the battery out 66 m from the lander |
| `14-merv-rover-companion.jpg` | MERV, the rover companion, keeping station off Jack's shoulder on a real rocker-bogie suspension |
| `15-merv-comms-sourced.jpg` | Rover comms: a sourced answer about Mars and a live weather read, with the tier and the wiring stated at the bottom |
